# C# OOP Tutorial for Beginners: Classes, Inheritance, Polymorphism and Interfaces (Roman English)

Complete C# Object-Oriented Programming tutorial with **26 topics**: classes, objects, constructors, encapsulation, inheritance, polymorphism, abstract classes and interfaces.

Har topic mein English technical definition, Roman English explanation, real-life example, syntax aur runnable code diya gaya hai.

## What You Will Learn

- OOP basics: what OOP is and why we use it
- Classes, objects, fields, properties and methods
- Constructors: default, parameterized and overloaded
- Access modifiers and encapsulation
- Inheritance: single, multilevel, hierarchical and multiple (via interfaces)
- Polymorphism: method overloading and method overriding
- `virtual` and `override` keywords
- Abstract classes, abstract methods and interfaces

## How to Run

Requirements: [.NET SDK](https://dotnet.microsoft.com/download) installed.

Har file ek alag example hai, isliye aik topic ek waqt mein chalayein:

```bash
dotnet new console -n OopLesson
# Topic file ka code OopLesson/Program.cs mein paste karein
dotnet run --project OopLesson
```

Note: sab files mein `Program` class aur `Main` method hai, is liye aik hi project mein ek se zyada topic files ek sath na rakhein.
